# Windows Authentication Failure Investigation

## 1. Objective

Verify that Wazuh detects failed Windows authentication attempts and investigate the resulting alert using the Wazuh Dashboard.

## 2. Test Scenario

A controlled authentication failure was generated by locking the Windows endpoint and entering an incorrect password. A successful auhtentication was then performed to unlock the worksation.

## 3. Detection

The following alert was identified in Wazuh:

| Field | Value |
|---|---|
| Date | November 13, 2026 |
| Time (UTC-3) | 02:05:02 |
| Agent | Windows10Pro |
| Windows Event ID | 4625 |
| Wazuh Rule ID | 60122 |
| Alert Level | 5 |
| Description | Logon Failure - Unknown user or bad password |

## 4. Investigation

The alert was located through the Threat Hunting section of the Wazuh Dashboard using the following query:

rule.id: 60122

The event details were inspected to identify the authentication type, source address and failure status.

| Field | Value |
|---|---|
| Event ID | 4625 |
| Logon Type | 2 |
| Source IP | 127.0.0.1 |
| Status | 0xc000006d |
| Authentication Package | Negotiate |

Logon Type 2 indicates an interactive logon attempt. The loopback source address is consistent with local authentication activity. The status code indicates an authentication failure.

## 5. Event Timeline

| Time (UTC-3) | Event | Event ID |
|---|---|---|
| 02:05:02 | Failed authentication | 4625 |
| 02:06:06 | Successful workstation unlock | 4624 |

The successful authentication occurred approximately four seconds after the failed attempt. This sequence is consistent with the controlled test scenario.

## 6. Alert Classification

- Classification: Benign true positive
- Malicious activity: Not idenfitified
- Response: No containment or remediation required

The alert correctly identified a failed authentication attempt. However, the activity was intentionally generated within the lab.

## 8. Conclusion

Wazuh successfully collected the Windows security event, generated an alert and made the event available for investigation through the Dashboard. The exercise demonstrated basic authentication monitoring, alert triage, event correlation and security event analysis.

## 9. Limitations

This investigation involved a single controlled authentication failure. It does not demonstrate brute-force detection or an actual account compromise.
